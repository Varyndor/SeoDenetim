# SeoDenetim

Free SEO and webmaster tools that run in the browser. Optional Search Console and Analytics panel. No signup for the tools.

**Site:** [https://www.seodenetim.com](https://www.seodenetim.com)

37 tools. Most stay in the browser and do not upload your files. Turkish UI; English SEO terms (`robots.txt`, sitemap, hreflang, Lighthouse, schema).

This repository is a public listing for the live product. Source is not published here.
